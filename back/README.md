# iGestor Backend

Backend REST de iGestor con Spring Boot 3, Java 21 y Maven.

## Ramas de aprendizaje

- `main`: base minima del proyecto.
- `dev`: rama de integracion para ir juntando avances.
- `feature/*`: ramas pequeñas para aprender y construir cada pieza.

## Arranque local

```bash
mvn spring-boot:run
```
